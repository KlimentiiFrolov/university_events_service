# notification_service

Сервис уведомлений в реальном времени.

- Consumer очередей RabbitMQ (события от `api_service`).
- WebSocket-эндпоинт, через который подключаются клиенты.
- Один процесс: consumer + WebSocket-приложение.

Порт: `8001`. Переменные окружения — см. `.env.template`.

Общее описание монорепо и трейдоффы подхода — в корневом [`README.md`](../README.md).
